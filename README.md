# Jobify

A full-stack **Job Management System** built with Angular, ASP.NET Core Web API, C#, and MySQL.

## 🚀 Features

* User Login & Profile
* Add, Edit & Delete Jobs
* Search Jobs
* Dashboard with Job Statistics
* REST API Integration
* MySQL Database

## 🛠️ Tech Stack

**Frontend:** Angular, TypeScript, HTML, CSS
**Backend:** C#, ASP.NET Core Web API, Entity Framework Core
**Database:** MySQL
**Tools:** Swagger, Git, GitHub

## ▶️ Run Locally

```bash
# Frontend
cd angular
npm install
ng serve

# Backend
cd Backend
dotnet restore
dotnet run
```

Configure your MySQL connection in the backend before running the application.
